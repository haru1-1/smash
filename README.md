# CAMPUS BREAKER — 3D 캠퍼스 아레나

전국 197개 캠퍼스를 검색하고 가상 3D 아레나에서 플레이하는 독립 제작 브라우저 게임입니다.

## 실행
- GitHub Pages: https://haru1-1.github.io/smash/
- Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 플레이
1. 첫 화면에서 학교 이름, 캠퍼스명 또는 지역을 검색합니다.
2. 캠퍼스를 선택하고 게임 시작을 누릅니다.
3. WASD 또는 방향키로 이동합니다.
4. 마우스 드래그로 카메라를 회전합니다.
5. 건물 가까이에서 클릭 또는 E 키로 점수를 얻습니다.
6. Q 키로 주변 건물을 대상으로 충격파를 사용할 수 있습니다.
7. 제한 시간 90초 안에 콤보를 이어 높은 점수를 기록하세요.

## 캠퍼스 데이터와 맵
- 학교 검색 목록은 197개 캠퍼스의 이름과 지역 정보를 포함합니다.
- 게임 맵은 캠퍼스 코드에 따라 생성되는 가상 3D 배경이며 실제 건물 배치나 높이를 재현한 지도는 아닙니다.
- 외부 지도 데이터를 불러오지 않아 캠퍼스 선택 후 빠르게 시작할 수 있습니다.

이 프로젝트는 SMASH 대학교에서 게임 아이디어를 얻어 별도의 코드와 그래픽으로 독립 제작한 비공식 팬 게임입니다. 원작의 코드, 그림, 화면 디자인을 복제하지 않았으며 각 대학과 공식적인 제휴 관계가 없습니다.
