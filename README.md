# SMASH CAMPUS — 3D 캠퍼스 브레이커

브라우저에서 실행되는 Three.js 기반 3D 캠퍼스 파괴 게임입니다. 실제 학교가 아닌 절차적으로 생성한 가상 캠퍼스에서 플레이합니다.

## 실행

- `index.html`을 브라우저에서 열거나 GitHub Pages를 활성화하세요.
- GitHub Pages 설정: 저장소 Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save
- 배포 주소: https://haru1-1.github.io/smash/

## 조작

- `W A S D` 또는 방향키: 이동
- 마우스 드래그: 카메라 회전
- 마우스 클릭 또는 `E`: 가까운 건물 공격
- `Q`: 범위 충격파 (재사용 대기시간 7초)
- 마우스 휠: 카메라 거리 조절

## 기술

- Three.js r160 / WebGL
- JavaScript 모듈
- 절차적 3D 건물·나무 생성, 간단한 파편 물리 효과

## 참고

이 프로젝트는 SMASH 대학교의 공식 게임이나 소스 코드 복제품이 아닌, Three.js와 절차적 생성 아이디어를 참고해 새로 만든 독립적인 프로젝트입니다. 실제 학교와 무관한 가상 캠퍼스입니다.
